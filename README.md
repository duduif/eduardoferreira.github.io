## 📝 Description

Personal-Website — a full-stack web app built with JavaScript, Next.js, Tailwind CSS.

## 🛠️ Tech Stack

- 🟨 **JavaScript**
- ▲ **Next.js**
- 🌬️ **Tailwind CSS**

**Notable libraries:** Framer Motion

## ⚡ Quick Start

```bash

# 1. Clone the repository
git clone https://github.com/duduif/Personal-Website.git

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```
